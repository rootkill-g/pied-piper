# WASI Preview 2 Components

Component model modules built for WASI Preview 2

## Status

This directory is reserved for future WASI Preview 2 (wasip2) examples.

WASI Preview 2 provides:
- Enhanced component model
- Better async support
- Improved I/O interfaces
- Resource handles

## Build (Future)

```bash
cd <example-name>
cargo component build --target wasm32-wasip2 --release
```
